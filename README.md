# 寻色｜色弱辅助 APP

图像处理课程小组项目。项目面向红绿色弱、蓝黄色弱等用户，计划通过色彩增强、颜色识别、纹理与语音提示帮助用户理解图像中的颜色信息。

## 当前阶段

第一周：需求、原型、素材、环境和协作规范准备。本仓库当前只有目录、文档和环境依赖清单；尚未实现算法、APP 功能或模型训练。

本地模板已准备；远程仓库创建、成员邀请、全员环境安装与验收需要团队实际执行，并在台账记录结果。

## 计划功能

1. 实时画面 Lab 色彩矫正滤镜。
2. 个性化色彩参数配置。
3. 单点颜色识别与双区域颜色比对。
4. 目标颜色查找与纹理高亮。
5. 颜色语音播报与场景告警。
6. 图表与静态图片的纹理辅助阅读。
