# 数据集目录

C 负责 traffic、indicator、warning、medicine；D 负责 chart、map、clothes、cosmetic。本周仅收集、分类、筛除无效素材和形成标注规范，标注文件格式由 C 定稿。

每类可使用 `img_001.jpg`、`img_002.jpg` 等连续命名。引用一张图片时使用类别和文件名的组合，例如 `chart/img_001.jpg`，避免跨目录重名产生歧义。原始图片不直接覆盖；后续处理结果放独立目录。

原始素材共享地址：待 C、D 填写。版本/张数/校验信息：待填写。能公开的素材可随项目提交；其余资料仅登记获取方式与使用条件。

来源登记见 SOURCES.md。当前子目录只有结构说明，没有真实采集图片。
